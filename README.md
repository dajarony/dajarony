## How I work

I prefer systems where behaviour can be explained and tested. That means clear contracts, small responsibilities, reproducible tests and explicit failure modes instead of hidden magic.

When AI is involved, I treat the model as a powerful but fallible component. The surrounding software should decide what the model may read, claim and execute.
